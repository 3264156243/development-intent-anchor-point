# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this plugin, please do **not** open a
public issue. Instead, report it privately:

- Open a [GitHub security advisory](https://github.com/3264156243/development-intent-anchor-point/security/advisories/new)
- Or send an email to the maintainer via the contact details on the repository.

We will acknowledge your report as soon as possible, work with you to understand
the scope of the issue, and coordinate a fix and disclosure.

## Scope

- The plugin skill instructions and its Python scripts under `plugins/`.
- The generated HTML questionnaire (it is fully local and offline; no data is
  sent anywhere unless you choose to share the exported `answers.json` with
  Codex yourself).
